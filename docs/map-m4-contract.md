# 中控地图 M4：房间交互与布局闭环

2026-10-03。仅演示模式开放，保留 Vue 2 和历史非演示配置路径。

## 交互

- `/floor/view` 单击名称或状态标记打开操作卡；「查看详情」打开房间抽屉，「进入房间」跳转该 roomId 的独立底图。无底图提示去房间管理上传，不借用其他房间底图。无需单击/双击区分业务操作。
- 操作卡显示在点击点旁，并限制到可视区域；配置中选中框右上角 × 与左侧移除按钮均将房间移回候选列表，不删除业务房间。
- `/floor/designer` 左侧显示当前楼层未放置房间，支持拖入或点击放置。画布单击选中，鼠标拖动移动；「移除布局」回左侧列表，不删除房间。
- 「撤销修改」恢复进入时的布局；「取消并退出」及其他路由离开遇到未保存草稿先确认。保存失败保留草稿；保存成功返回预览。支持保存空列表清空本层布局。

## 接口与存储

复用 `POST /map/element/config`，增加明确对象 schema：

```json
{"type":11,"floorId":930001,"mediaId":940001,"list":[{"type":11,"elementId":950001,"mediaId":940001,"x":400,"y":200}]}
```

该对象只用于楼层房间布局；原设备数组/list schema 保留，不能混合。接口沿用会话保护，验证楼层、mapId、房间归属、重复 ID、有限数值及边界后一次写入 `smart-facility-demo:v1:floorRoomLayout`。不保存房间名称或业务字段的副本；读取按共享 roomId 合并最新业务信息。

坐标使用 1678×795 基准空间；显示 ratio 不持久化。标记框按 180×40 限定，x 范围 0..1498、y 范围 0..755。PNG/SVG 均按现有楼层基准渲染，不自动迁移旧坐标或裁剪房间图。

未保存过布局的楼层继续读种子标记；保存过的楼层以完整快照为准，包括空快照。候选列表与预览读取同一快照。

业务房间删除时清除布局索引；换楼层时清除旧布局，并将历史坐标标记为未布局，换回也不复活旧坐标。房间内设备布局不受本接口影响；有关联房间的删除约束保留。

## 验证及限制

- 全量 49 套、248 项单测通过；M4 覆盖移除、空快照、非法/混合布局、换楼层、新建房间、删除清理、存储失败、接口会话。
- `scripts/check-demo-map-m4.cjs` 浏览器通过：操作卡/详情/导航、候选拖入事件、实际鼠标拖动、移除回列表、保存刷新、取消离开确认且旧快照不变；外部请求 0。证据 `docs/evidence/map-m4/`。
- 候选拖入测试通过浏览器 DragEvent/DataTransfer 派发；画布移动为真实 CDP 鼠标序列。未做完整触屏/多分辨率验收，字体批量设置继续不开放。
- 当前楼层基准尺寸沿用原坐标契约，不实现任意尺寸底图的坐标自动迁移；不扩大到 M5 设备管理联动。
