# 智慧设施助手跨端适配与实际验证

验证记录日期：2026-10-28（Asia/Shanghai）；导览与截图同步：2026-10-29。本次基于 `miniprogram` 原 Vue 2 uni-app 工程适配 H5。

当前先完成 H5 核心展示；Android / iOS 尚未交付安装包，真机、签名和账号限制分别记录。原工作中的小程序有部署上线经验，当前 H5 适配属于个人脱敏作品的 AI 协作整理阶段。

此前脱敏展示副本以源码和本地运行方式展示，未提供公网入口。本次曾新增第三方静态托管尝试，但实际访问被托管域名安全服务拦截，当前不作为可靠的面试访问入口。下文托管记录只说明本次适配阶段的尝试，不代表原公司的线上系统或其可用性。

## 本轮变更

- 为 H5、微信小程序和 App 资源编译提供统一脚本，保留 uni-app 条件编译和微信专有能力。
- 嵌套设备列表、设备/房间详情、告警列表及选时组件使用 Vue 组件生命周期初始化，避免仅在小程序页面钩子下加载。
- 修复懒加载弹窗在挂载时访问不存在的表单、重置表单时丢失 `this`、运单确认自定义事件误用 `.stop` 的问题。
- 首页快捷入口改为弹性布局；修复自定义导航测量、Tab 文本挤压和选中状态，H5 桌面内容宽度限制为 480px。
- H5 使用独立 HTML 模板和 hash 路由，加载 uni-app 基础 CSS；将导航阴影改为 CSS 渐变，避免运行时依赖外部图片。
- 修复监测状态图标的动态相对路径。移除未启用的真实蓝牙打印组件引用，凭证预览仍保留。
- 删除带旧 AppID 的重复 `project.config.json`，由 uni-app 根据 `manifest.json` 生成微信配置。
