# M6：设备混合状态

本轮仅处理用户指定的默认混合展示，其余 M6 任务未开展。

- 默认 `mixed`：房间 A 全正常；房间 B 的演示示波器 B（970008）告警，其余正常。新增设备默认正常。
- 楼层及房间预览移除全局场景按钮，保留筛选。筛选不修改数据或布局。
- 楼层默认全部显示，筛选同步控制名称、状态标记及数据浮层：正常仅 A、报警仅 B、离线为空，全部关闭隐藏所有标记。左上角展开楼层统计侧栏，独立统计全层布局设备（11 正常、1 告警、0 离线），逐房间展示，可点击进入房间并关闭侧栏；侧栏带关闭按钮。
- 设备状态源 `statusForInstrument`；房间按业务归属设备聚合，告警优先于离线和正常。没有设备的房间保留独立房间监测状态，走廊默认未监测。
- 从地图移除设备不删除档案，也不会消除房间告警；设备换房间时，两边聚合状态同步变化。
- 告警温度 45.2℃，上限 40℃；湿度 85%，上限 70%。地图悬停、详情及大屏共用读数，大屏房间卡注明代表设备名称。
- 旧 `/demo/scenario` API 与测试重置正常状态的辅助函数仅保留兼容回归；页面无入口。默认重新加载模块恢复混合状态，不改生产接口或历史报警记录。

验证：`npm run test:demo -- --watch=false --silent`，51 套、257 项通过。浏览器脚本 `scripts/check-demo-map-m6-status.cjs`，用独立本地端口验证 A/B 默认状态及场景按钮移除。
