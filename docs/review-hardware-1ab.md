## 收尾问题

1. P1：只读详情仍暴露管理操作。DeviceDrawerNew.vue:14 的 level 条件对 demo 管理角色成立；509/529 的声光、平台报警开关设置 fullscreenLoading=true，调用未接入接口且无 catch/finally。mock/adapter.js 对未匹配接口抛错，导致 loading 无法复位、开关无法回滚。549 的其它弹窗操作也没有 demo 能力拦截。应明确能力边界并补错误恢复，不靠所有请求统一 501 代替页面禁用。
2. P2：指标契约与状态不一致。已有 01-recorder-detail.png 可见报警范围 undefined；equipment.js 的 sensorReading 统一使用 normalMin/normalMax，须追踪最新状态子组件真正读取的字段。同文件温度类阈值 40、压差阈值 100，与告警样本阈值 30/10 不一致。温湿度使用单值和混合单位；信号强度 3 被页面展示为 3dBm，需核实单位语义。
3. P2：离散量曲线被连续值算法处理。equipment.js:317 将合法 0 用 ||20 替代；322 对所有值加浮点波动，水浸曲线因此不符合 0/1 语义。应按指标类型生成，温湿度也应核实独立通道契约。
4. P2：离线告警标签可能显示阈值告警。HistoryAlarmRecord/index.vue 离线分支传 objId/objType；listEquipmentHistoryAlarms 在 objId 分支仍返回同一阈值告警集合（equipment.js:375 起），未区分离线事件。告警设备切换离线标签会得到错误类别记录。
