## 契约

- 统一 `src/mock/fixtures/instrument.js`：种子、手动新增和 XLSX 导入共用 ID、名称、分类、房间归属。新增不自动上图；候选 = 当前房间有效档案减去草稿已放置 ID。
- 编辑 `/instrument/update/basic` 支持 `roomId`。改名/分类在布局读侧动态合并；换房间清除原位置，新房间待放置，移回不复活旧位置。档案写失败时尝试恢复原布局。
- 设备布局 `/map/element/config` 使用 `{type:4,roomId,list}`。每项保留 `type:4 / elementId / mediaId:roomId / x / y / rotation / scaleX / scaleY / sortIndex`。兼容既有非空数组。对象必须提供有效房间。
- 部分/空列表均为完整替换快照，空快照不回退种子。未知/重复设备、跨房间、混合类型、非有限坐标、非法缩放、越界整次拒绝，写失败返回错误。读侧仍用 `/map/element/getRoonInstrumentInfoList?roomId=`。
- 楼层房间的 `type:11` 对象契约保持，不能混用。设备业务删除仍须先解绑智能硬件，删除清理布局；仅移除布局保留档案。
- 手动新增及导入设备计入房间关联检查，防止删除仍有设备的房间；导入选项随当前房间列表更新。

- 设备从左侧拖入或点击居中放置；保留移动、缩放和旋转。选中后右上角圆形 × 移除，原双击移除可用；返回候选，仅保存写入。
- 撤销草稿、未保存退出确认；成功保存立即返回预览，离场即时隐藏配置层，避免路由动画遮挡。
