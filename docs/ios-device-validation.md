# iOS 真机运行与验证记录

日期：2026-10-30（Asia/Shanghai）。同一 uni-app Vue 2 工程已在 iPhone 真机运行，完成登录、导航、图表及预约主线验证；拔掉 USB 后可继续使用，退出重进后取消记录保留。

## 环境与落地方式

- Windows、HBuilderX 5.33、iPhone 15 Pro，Sideloadly 设备列表显示 iOS 26.6.2。
- 使用普通 Apple 账号免费签名安装 HBuilder iOS 标准基座，未购买 Apple Developer Program 会员，无需本地 Mac / Xcode。
- 完成手机开发者模式与开发者信任配置，HBuilderX 日志显示手机端程序文件同步成功、项目已启动。
- Sideloadly 的 Export IPA 在没有修改项目时提示 Nothing to export，未用该方式作为签名成功依据。随后从本地已有签名缓存及手机对应描述文件准备签名材料，通过 HBuilderX 自带签名工具生成基座；核对包标识与描述文件匹配，基座包含描述文件和代码签名资源，再放入 HBuilderX 标准基座目录。
- 手机已安装并运行的包仍为 HBuilder 调试基座；项目业务代码由 HBuilderX 同步。该方式支持当前手机脱离电脑使用，不属于项目独立发行 IPA 或 App Store 发布。

## 验证边界与交付

- 已完成上述主线；iOS 报警处理、运单操作闭环、完整键盘遮挡、横屏、更多设备及系统版本暂未作为已通过项目。
- 当前验证的是实际 iPhone 上的 uni-app App 运行，不是 Safari 中的 H5。拔 USB 不等于关闭网络，本轮没有据此声明飞行模式或完整离线能力。
- 免费签名有有效期，过期需要重新签名；修改项目代码需要重新同步。现有签名面向登记的测试设备，不作为可直接向面试官分发的长期安装包。
- 签名私钥、P12、密码、描述文件及签名 IPA 均保存在本地缓存/已忽略的 `.tmp/` 或 HBuilderX 插件目录，不提交 Git。文档不记录 Apple 账号、Team ID 或设备 UDID。
- 业务使用本端本地 Mock；真实蓝牙、打印、枪架硬件、微信授权及真实推送不属于验收范围。
