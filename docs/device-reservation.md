# 设备预约闭环

设备详情的“新增预约”开放日历。拖选未来时段新增，点击预约修改或取消；取消须确认，保存后保留日历并刷新。

- 预约按设备隔离，保存在演示专用 localStorage，刷新可重新读取。
- 日历和详情“预约使用记录”共用同一份数据，保存后同步刷新。取消的预约保留为“已取消”记录，日历隐藏并释放该时段；列表支持分页。
- 拒绝缺失、非法、过去及结束不晚于开始的时间。同一设备不可重叠，前一预约结束等于后一预约开始允许。
- 进行中预约保留开始时间，可以调整未来的结束时间；已结束预约不能编辑。
- 日历切换日期以最新请求为准，避免旧请求覆盖；刷新不会形成日期事件循环。
- 使用当前实际日期，不采用历史监测图表的固定演示日期。
- 仅本地演示预约，不发送通知，也不接通外部预约服务。

验证：55 个单测套件、269 项测试通过；本地浏览器验证详情入口、日历选时、新增、点击编辑、重新读取和确认取消，外部网络请求为 0。证据位于 docs/evidence/reservation。
