# 运单演示契约

日期：2026-10-06。范围：SaaS 运单主页/列表/详情/创建/装车/发运/送达；小程序运单列表/统计/详情/发运/送达。两端**各自本地 Mock**，合成 ID/编号/状态规则一致，**不**跨端实时同步。SaaS 承担创建；小程序不提供创建入口。

## 查询条件 ≠ 实体状态

| 端 | 查询字段 | `0` / 空 / `null` | `1` | `2` | `3` |
| --- | --- | --- | --- | --- | --- |
| 小程序 `state` | 列表筛选 | **全部**（页面会把 `0` 清成空再请求） | 已装车 | 运输中 | 已送达 |
| SaaS `state` | 列表筛选 | `null` = 全部 | 已装车 | 运输中 | 已送达 |
| 实体 `order.state` | 记录本身 | **待装车** | 已装车 | 运输中 | 已送达 |

不得把小程序统计卡的「全部=`state:0`」写成待装车。

## 实体状态机

合法迁移：`0→1→2→3`。禁止跳状态、回退、重复装车/发运/送达。失败不改记录。

| 动作 | 目标 | 校验 |
| --- | --- | --- |
| 创建 | `0` | 收发单位 ID、至少一件货、数量为正整数；运单号本地生成 |
| 分配车辆 | 仍为 `0` | 车辆/司机 ID 必须存在；运输中占用的车辆/司机不可再分给其它运单 |
| 装车 `1` | 仅 `0` | 必须已有车辆和司机 |
| 发运 `2` | 仅 `1` | 必须已有车辆和司机；同车其它已装车运单一并进入运输中（发车确认） |
| 送达 `3` | 仅 `2` | 到达后释放该车/司机占用（若已无其它 `1/2` 运单） |

时间顺序：`createDate` ≤ `loadingTime` ≤ `beginTime` ≤ `completeTime`。缺段为空，不得倒序写入。

## 异常是独立维度

`tempOverrun`（温度超限）与 `delayed`（相对计划发运延迟）**不是**运输状态，可与 `2/3` 并存。列表监测值与详情阈值、曲线同源。

## 存储（退出保留）

## 接口（以源码为准）

小程序 `/api`：`GET /transportOrder/dashboard/wx`、`POST /transportOrder/list/wx`、`GET /transportOrder/detail/wx/:id`、`GET /transportOrder/change/getStateInfo`、`POST /transportOrder/change/state`。打印预览可返回**演示凭证**；蓝牙打印拒绝。

Web（无 `/api`）：`POST /transportOrder/query`、`add`、`update`、`allocateCar`、`change/state`、`GET /transportOrder/detail/:id`、`dashboard`、`change/getStateInfo`、同源下拉（司机/车辆/货品/收发单位）、监测/报警/模拟 GPS。导出与基础资料 CRUD **拒绝**。
