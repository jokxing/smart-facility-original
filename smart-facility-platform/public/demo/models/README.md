# Demo building models

Local GLB files for the `/building` demonstration. The office model is third-party; the other models are synthetic placeholders.

| File | Registry key | Visual difference |
| --- | --- | --- |
| `office-building-low-rise.glb` | `demo-building-a` | Textured low-rise office building |
| `building-a.glb` | Not registered (fallback asset) | Tall blue box |
| `building-b.glb` | `demo-building-b` | Medium green box |
| `building-c.glb` | `demo-building-c` | Short amber box |

- **Placeholder source (building-a/b/c only)**: generated by `node scripts/generate-demo-models.cjs` (self-contained binary GLB, PBR color only, no textures, no external buffers).
- **Not** original customer models; do not download or link remote file APIs.
- Regenerate placeholders with the same script if missing; the downloaded office model is not generated by it. Keep keys registered in `src/utils/demoModelUrl.js`.
